## Installation
1. Clone the repository
```
git clone https://github.com/Obaidkhan19/Dockerized-Notes-Application-with-Nginx
```

2. Build the app
```
docker build -t notes-app .
```

3. Run the app
```
docker run -d -p 8000:8000 notes-app:latest
```

## Nginx

`sudo apt-get update`
`sudo apt install nginx`
